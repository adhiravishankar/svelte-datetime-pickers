# svelte-datetimerange-picker

A datetime range picker for your Svelte 5 app.

- Pick days, months, years, or even decades
- Supports virtually any language
- No moment.js needed

## tl;dr

- Install by executing `npm install svelte-datetimerange-picker svelte-date-utils`.
- Import by adding `import DateTimeRangePicker from 'svelte-datetimerange-picker'`.
- Use by adding `<DateTimeRangePicker />`. Use the `onChange` prop for getting new values.

## Consider native alternative

If you don't need to support legacy browsers and don't need the advanced features this package provides, consider using native datetime input instead. It's more accessible, adds no extra weight to your bundle, and works better on mobile devices.

```svelte
<input aria-label="Date and time from" max={valueTo} min={minDatetime} type="datetime-local" />
<input aria-label="Date and time to" max={maxDatetime} min={valueFrom} type="datetime-local" />
```

## Getting started

### Compatibility

Your project needs to use Svelte 5 or later. The picker relies on modern web technologies (`Intl`), so it [supports only modern browsers](https://caniuse.com/#feat=internationalization).

### Installation

Add svelte-datetimerange-picker and its date adapter utilities to your project by executing `npm install svelte-datetimerange-picker svelte-date-utils`.

### Usage

```svelte
<script lang="ts">
  import DateTimeRangePicker from 'svelte-datetimerange-picker';
  import { AdapterDate } from 'svelte-date-utils';
  import { provideDateAdapter } from 'svelte-date-utils/svelte';

  type ValuePiece = Date | null;

  type Value = ValuePiece | [ValuePiece, ValuePiece];

  provideDateAdapter(new AdapterDate());

  let value = $state<Value>([new Date(), new Date()]);
</script>

<DateTimeRangePicker onChange={(nextValue) => (value = nextValue)} {value} />
```

The adapter is required and is read from Svelte context. Call `provideDateAdapter(adapter)` in this component or an ancestor before rendering the picker. Without a provider, the picker throws an error. The selected adapter determines the date object type used by `value` and `onChange`; `AdapterDate` uses native `Date`. For date-fns, Luxon, or `@internationalized/date`, use the matching adapter exported by `svelte-date-utils/date-fns`, `svelte-date-utils/luxon`, or `svelte-date-utils/internationalized`.

### Styling

Styles for the picker, the calendar and the clock are imported automatically. All elements use BEM class names starting with `svelte-datetimerange-picker`, `svelte-calendar` and `svelte-clock`, so you can build on them.

If you prefer to import the stylesheets yourself, they are available as `svelte-datetimerange-picker/dist/DateTimeRangePicker.css`, `svelte-range-calendar/dist/Calendar.css` and `svelte-analog-clock/dist/Clock.css`.

### Migrating from React-DateTimeRange-Picker

- `className` → `class`; `calendarProps.className` → `calendarProps.class`; `clockProps.className` → `clockProps.class`.
- React nodes and components in `calendarIcon`, `clearIcon` and `rangeDivider` → strings or snippets.
- Event props are the lowercase DOM ones (`onclick`, `ontouchstart`, …), except `onFocus`, which is called on bubbling focus events like in React.
- `data-testid` and `id` are passed through as regular attributes.
- Stylesheets are imported automatically, and CSS classes use the `svelte-` prefix instead of `react-`.

The picker is built from these packages, which you can also use on their own:

- [svelte-date-input](https://github.com/adhiravishankar/svelte-datetime-pickers/tree/main/packages/svelte-date-input): segmented date input fields and the shared engine.
- [svelte-range-calendar](https://github.com/adhiravishankar/svelte-datetime-pickers/tree/main/packages/svelte-range-calendar): calendar with range selection.
- [svelte-analog-clock](https://github.com/adhiravishankar/svelte-datetime-pickers/tree/main/packages/svelte-analog-clock): analog clock.
- [svelte-fit-action](https://github.com/adhiravishankar/svelte-datetime-pickers/tree/main/packages/svelte-fit-action): `fit` and `portal` actions.
